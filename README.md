# OIBSIP_WEB-DEVELOPMENT-DESIGN_2
# 💼 Personal Portfolio Website

## Overview

This project is a responsive Personal Portfolio Website developed using HTML and CSS. The portfolio serves as a digital resume and showcases my skills, projects, education, and contact information. It is designed to provide visitors with a clear overview of my background and technical abilities.

---

## Features

* Responsive Navigation Bar
* Hero Section with Profile Image
* About Me Section
* Skills Showcase
* Projects Section
* Resume Download Button
* Contact Information
* Social Media Links
* Smooth Hover Effects
* Mobile-Friendly Design

---

## Technologies Used

* HTML5
* CSS3
